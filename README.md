# Blinkit Business Analytics Dashboard

An interactive business analytics project built with Python, Streamlit, Pandas, and Plotly. The dashboard explores marketing campaign performance, delivery operations, customer feedback, and inventory quality using a Blinkit-themed practice dataset.

## Live Dashboard

[Open the interactive dashboard](https://sachit191-blinkit-business-analytics-app-e6pffp.streamlit.app/#blinkit-business-analytics)

## Project Objectives

- Analyze marketing channel performance using impressions, clicks, conversions, revenue, and Return on Ad Spend (ROAS).
- Examine delivery status and deviation from promised delivery times.
- Explore customer feedback volume and average ratings by sentiment.
- Assess inventory damage using received and damaged unit counts.

## Tools & Technologies

- Python
- Streamlit
- Pandas
- Plotly
- Jupyter Notebook / Google Colab

## Dashboard Sections

| Section | Analysis |
|---|---|
| Marketing | Revenue, ROAS, campaign metrics, and channel filters |
| Delivery | On-time and delayed order distribution |
| Customer Feedback | Sentiment volume and average ratings |
| Inventory | Received units, damaged units, and damage rate |

## Key Findings

- Email had the highest ROAS among the four analyzed marketing channels.
- 69.4% of orders were classified as on time in the dataset.
- Negative feedback had an average rating of approximately 2.01.
- Inventory damage rate was approximately 5.53% of received units.

## Repository Contents

## Note on Data

This is a portfolio project using a Blinkit-themed practice dataset. The results are exploratory and **are not official Blinkit company metrics**. Customer-level data is not included in this public repository.
